# 23: Applicare budget progressivi allo schema UML

Status: ready-for-agent
Type: task
Blocked by: None (can start immediately)

**What to build:** Uno schema grande deve produrre rapidamente un UML navigabile entro
budget, caricando dettagli aggiuntivi soltanto su richiesta.

- [ ] Il contratto dello schema dichiara totali, dati omessi e possibilità di continuazione
- [ ] Il primo risultato limita collezioni, colonne e relazioni secondo budget espliciti
- [ ] L'utente può richiedere progressivamente i dettagli omessi
- [ ] La vista comunica chiaramente quando mostra un riepilogo incompleto
- [ ] Test con uno schema sintetico grande verificano payload e responsività
- [ ] Schemi piccoli mantengono il comportamento completo attuale
- [ ] La controprova senza budget supera il limite fissato dal test
