## Descrizione

CodeDB Manager è un'app desktop per esplorare e gestire database MongoDB, MySQL e PostgreSQL da un'unica interfaccia. Per utilizzarla occorre avere accesso a un database compatibile, locale o remoto, e alle relative credenziali: l'app non include un server database.

Questa è una versione beta, destinata a chi vuole provare CodeDB Manager e contribuire al suo miglioramento con segnalazioni e suggerimenti.

Esplora tabelle e collezioni, filtra e ordina i risultati, modifica i dati ed esegui query SQL o MongoDB. Organizza il lavoro in schede e affianca più viste per confrontare dati e risultati.

Funzionalità principali:

- Connessioni a MongoDB, MySQL e PostgreSQL, anche tramite tunnel SSH.
- Consultazione e modifica di tabelle e documenti con filtri, ordinamento e paginazione.
- Editor di query e script con completamento automatico e cronologia locale.
- Importazione ed esportazione dei dati nei formati supportati dal motore selezionato.
- Diagrammi delle relazioni, grafici e visualizzazione dei dati geografici su mappa.
- Strumenti di backup e ripristino, con opzioni disponibili in base al database.
- Salvataggio delle connessioni e protezione delle credenziali mediante vault con passphrase.
- Interfaccia in italiano, temi chiaro e scuro e viste affiancate.

CodeDB Manager include il proprio ambiente di esecuzione: non occorre installare separatamente Node.js per avviare l'app. Le connessioni ai database e i servizi esterni utilizzati richiedono l'accesso alla relativa rete. Le mappe di sfondo e i caratteri dell'interfaccia possono richiedere una connessione Internet.

La beta può contenere errori e le funzionalità possono cambiare. Per le prime prove utilizza database di test o copie dei dati e conserva backup aggiornati prima di eseguire modifiche, cancellazioni o ripristini.

CodeDB Manager è software open source, distribuito con licenza AGPL-3.0-only. Gli aggiornamenti di questa edizione sono distribuiti tramite Microsoft Store.

Assistenza e segnalazioni: info@codedb.org
